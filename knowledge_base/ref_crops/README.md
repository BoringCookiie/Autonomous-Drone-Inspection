# Reference Image Crops Directory

Directory containing exemplar reference crops categorized by defect class:
- `erosion/`: Reference crops for surface erosion and spalling.
- `structural_crack/`: Exemplars of cracks and masonry fractures.
- `moisture_stain/`: Reference images for dampness and efflorescence.

Used by `scripts/build_clip_embeddings.py` to pre-calculate image feature vectors.
