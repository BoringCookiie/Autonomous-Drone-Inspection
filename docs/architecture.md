# System Architecture & Technical Specifications

## 1. Decoupled Waypoint Inspection Loop

Standard drone video streaming often suffers from motion blur and excessive data redundancy. Our architecture decouples flight navigation from defect processing using a **Per-Waypoint Capture Strategy**:
1. The UAV navigates a coverage lawnmower pattern generated by the A* planner.
2. Upon reaching a target waypoint, the navigation stack emits a ROS2 signal `/uav/waypoint_reached`.
3. `per_waypoint_capture_node` captures synchronized RGB and Depth frames, freezes sensor state, and publishes to `/inspection/captured_frame`.

## 2. Multi-Backend Defect Detection Node

The core AI module (`detection_node`) encapsulates three interchangeable backends behind a unified detector interface:

1. **`raw_vlm`**: Zero-shot Vision-Language Model (e.g., LLaVA / Qwen-VL) queried with raw defect prompt templates.
2. **`rag_vlm`**: Knowledge-grounded Zero-shot VLM. Embeds target image crops via CLIP, retrieves top-$k$ domain descriptions from `defect_ontology.json`, and appends grounded domain context into the VLM prompt.
3. **`yolo`**: Supervised YOLOv11 detector fine-tuned on earthen heritage defect datasets (SDNET2018 + MBDD2025 + domain augmentation).

All backends output standard bounding boxes, defect labels, and confidence scores $C \in [0.0, 1.0]$.

## 3. Confidence-Triggered Revisit Generator

When detection confidence $C$ falls within an ambiguous range:
$$C_{min\_amb} \le C \le C_{max\_amb} \quad (e.g., \, 0.4 \le C \le 0.7)$$

The system triggers an autonomous revisit flight maneuver:
1. **3D Projection**:
   Using camera intrinsic matrix $K = \begin{bmatrix} f_x & 0 & c_x \\ 0 & f_y & c_y \\ 0 & 0 & 1 \end{bmatrix}$ and depth map $Z$, the 2D bounding box center $(u, v)$ is unprojected into 3D camera coordinates:
   $$X = \frac{(u - c_x) \cdot Z}{f_x}, \quad Y = \frac{(v - c_y) \cdot Z}{f_y}$$

2. **Adaptive Revisit Standoff Distance**:
   The revisit distance $D_{revisit}$ is dynamically scaled based on uncertainty:
   $$D_{revisit} = \max\left(D_{min}, \; D_{base} - k \cdot (1 - C)\right)$$
   where $D_{base}$ is the nominal standoff distance (e.g., $3.0\text{m}$), $D_{min}$ is safety clearance ($1.0\text{m}$), and $k$ is the uncertainty scaling factor ($2.0$).

3. **Waypoint Enqueueing**:
   The calculated 3D revisit pose is enqueued directly to the A* global path planner via `/planner/revisit_waypoints`.

## 4. Evaluation Matrix (6 Conditions)

| ID | Backend | Strategy | Primary Focus |
|----|---------|----------|---------------|
| C1 | `raw_vlm` | `single_pass` | Baseline VLM zero-shot accuracy |
| C2 | `raw_vlm` | `revisit` | Revisit effect on ungrounded VLM |
| C3 | `rag_vlm` | `single_pass` | RAG grounding impact on baseline pass |
| C4 | `rag_vlm` | `revisit` | Full proposed RAG + Revisit loop |
| C5 | `yolo` | `single_pass` | Supervised fast detector baseline |
| C6 | `yolo` | `revisit` | Supervised fast detector + Revisit loop |
